PRD — Live Preview Engine
Feature Name

Live Preview Engine

Resumen

Sistema de preview interactivo que permite visualizar cambios de edición en tiempo real SIN re-renderizar video.

El engine simula:

trims,
captions,
estilos,
posiciones,
tamaños,
safe areas,

directamente en el navegador usando:

playback control,
overlays HTML/CSS,
estado UI local.

El render final real ocurre únicamente al exportar.

Problema

Actualmente, cualquier cambio visual que requiera:

render backend,
ffmpeg,
generación de nuevo MP4,

introduce:

latencia,
costo,
mala UX,
fricción creativa.

La experiencia ideal requiere:

feedback instantáneo,
edición fluida,
interacción continua.
Objetivo

Hacer que el usuario sienta:

“estoy editando el video en tiempo real”

sin renderizar realmente durante la edición.

Objetivos del producto
Primarios
eliminar espera entre cambios,
aumentar sensación de fluidez,
aumentar interacción con editor,
aumentar export rate.
Secundarios
reducir renders innecesarios,
reducir costo backend,
habilitar futuras features creativas.
Principio central
El preview es una simulación visual

NO:

un render,
un nuevo mp4,
un encode real.
Alcance

El usuario puede:

2. Live captions preview
Captions renderizados como overlays HTML/CSS

NO burned-in durante edición.

Cambios instantáneos
estilo,

Definición de éxito

La feature es exitosa si:

el editor se siente instantáneo,
el usuario nunca espera renders durante edición,
y el export ocurre únicamente una vez al final.
