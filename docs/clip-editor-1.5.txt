PRD — Quick Creative Editor (V1.5)
Feature Name

Quick Creative Editor

Resumen

Editor liviano integrado al flujo de AI clipping que permite:

ajustar timings del clip,
previsualizar cambios instantáneamente,
personalizar captions,
y exportar un clip listo para publicar.

La feature NO busca reemplazar editores profesionales.

Objetivo:
dar control creativo rápido sin romper la simplicidad del producto.

Objetivo del producto

Convertir:

AI-generated clips

en:

publish-ready short-form content

con menos de 1 minuto de edición manual.

Problema que resuelve

Los clips automáticos suelen fallar en detalles:

hook empieza tarde,
final abrupto,
captions no gustan,
texto tapa cara,
estilo visual no encaja,
clip no parece “nativo” de TikTok/Reels.

El usuario necesita:

pequeños ajustes,
no edición profesional completa.
Objetivos de negocio
Primarios
aumentar export rate,
aumentar satisfacción con clips,
aumentar perceived quality,
mejorar shareability.
Secundarios
aumentar retención,
aumentar tiempo en producto,
mejorar diferenciación frente a competitors.
Principios de diseño
1. Fast-first

Toda interacción debe sentirse instantánea.

2. Lightweight editing

No competir con CapCut.

3. Presets over complexity

Mejor:

presets,
toggles,
sliders simples,

que controles infinitos.

4. AI-first

La IA sigue haciendo:

selección,
timing base,
captions,
composición inicial.

El usuario solo refina.

Arquitectura técnica

Renderiza

Renderiza

Genera

metadata timeline.
Pipeline técnico
1. AI genera clip

Output:

{
  "clip_start": 1315,
  "clip_end": 1365
}
2. Backend genera editor assets
Assets
Proxy video

Ejemplo:

480p,
bitrate bajo.
Thumbnail strip

Frames cada X segundos.

Captions JSON
[
  {
    "start": 1.2,
    "end": 2.4,
    "text": "this changes everything"
  }
]
3. Frontend monta editor

Usa:

proxy,
overlays,
captions HTML.
4. Usuario modifica settings

Estado local:

{
  "start": 1312,
  "end": 1369,
  "caption_style": "viral",
  "caption_position": "center",
  "caption_size": "large"
}
5. Export

Frontend manda config.

6. Backend renderiza final

ffmpeg:

corta original,
aplica subtitles,
exporta MP4 final.

Definición de éxito

La feature es exitosa si:

el usuario puede ajustar y estilizar un clip en menos de 1 minuto,
